- **离线分析与报告**: 周报/月报生成、文档摘要等非实时任务，周末调用性价比最高。

### 什么场景不值得用

- **实时在线服务**: 用户等待的对话/推荐服务无法等到周末，工作日高峰仍需支付 ¥27/MTok 的 V4-Pro 输出价。

- **小量调用**: 如果每月只调用几万次，峰谷价差的实际节省金额有限，不值得为此改造调度逻辑。
- **对价格极度敏感但无法错峰的场景**: 如果必须在高峰时段调用且对成本敏感，应考虑 V4-Flash 而非 V4-Pro。

- **从固定价迁移到峰谷定价**: 需要改造调度层，增加时间判断逻辑。如果是简单的 cron 任务，改触发时间即可；如果是动态 Agent 框架，需要在调度器层面加入成本感知逻辑。
