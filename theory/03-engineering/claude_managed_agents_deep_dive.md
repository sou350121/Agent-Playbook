## 是什么 / 解决什么问题

### 背景痛点

在 Claude Managed Agents 发布之前，构建生产级 Agent 意味着：
- 需要自建**沙箱代码执行环境**（防止恶意代码）
- 实现**状态管理和检查点**（支持长周期任务）
- 开发**凭证管理系统**（安全存储 API keys、数据库密码）
- 设计**权限边界**（Agent 能访问什么、不能访问什么）
- 构建**端到端追踪系统**（调试、审计、合规）

这些基础设施工作通常需要**数月的开发周期**，在用户看到任何价值之前就已经消耗了大量工程资源。

### 这次变化的核心

Anthropic 于 2026 年 4 月 8 日推出的 Claude Managed Agents，本质上是一个**托管的 Agent 运行时平台**。开发者只需定义：
- Agent 的任务目标
- 可调用的工具列表
- 安全边界和权限规则

Anthropic 负责运行基础设施，包括：
- 安全的沙箱环境
- 会话状态持久化
- 工具调用编排
- 错误恢复机制
- 完整的执行追踪

官方声称可将**从原型到上线的时间从数月缩短到数天**（10x 加速）。

### 什么场景值得用

### 什么场景不值得用

| 场景 | 理由 | 替代方案 |
|------|------|----------|
| **简单单次调用** | $0.08/会话小时成本不划算 | 直接用 Claude API |
| **成本极度敏感** | 托管溢价可能超过自建成本 | 开源框架 + 自运维 |

### 迁移成本

**从自建迁移到 Managed Agents**:
- **代码改动**: 中等 — 需重写 Agent 循环以适配托管编排器
- **工具适配**: 低 — 工具定义接口相对标准
- **数据迁移**: 低 — 会话状态由平台管理
- **学习成本**: 中等 — 需熟悉 Claude Console 和 API
- **预计工作量**: 1-2 周（单人）

**从 Managed Agents 迁移回自建**:
- **风险**: 中高 — 编排逻辑和追踪系统需重新实现
- **建议**: 在架构设计时保持工具层与运行层解耦

## 关键代码/配置片段

### 启动 Managed Agent 示例

```python
# 通过 Claude API 启动托管 Agent
from anthropic import Anthropic

client = Anthropic()

agent = client.beta.managed_agents.create(
    name="code-reviewer",
    model="claude-sonnet-4-20260514",
    instructions="You are a code review agent. Review PRs and suggest improvements.",
    tools=[
        {
            "type": "code_execution",
            "sandbox": "python",
        },
        {
            "type": "file_read",
            "allowed_paths": ["/repo/src"],
        },
        {
            "type": "github_pr_comment",
            "scope": "read_write",
        }
    ],
    guardrails={
        "max_session_hours": 4,
        "allowed_domains": ["github.com"],
        "require_human_approval_for": ["code_write"],
    }
)

# 启动会话
session = client.beta.managed_agents.sessions.create(
    agent_id=agent.id,
    input="Review PR #1234 in repository X",
)

# 追踪执行
for event in session.stream():
    print(event.type, event.data)
```

### 定价结构

```
标准 Claude Platform token 费率 + $0.08 / 会话小时（活跃运行时）

示例计算:
- 一个运行 2 小时的代码审查 Agent
- 消耗 50,000 input tokens + 10,000 output tokens
- 假设 Sonnet 4 费率: $3/1M input + $15/1M output
- Token 成本: (50000 * 3/1000000) + (10000 * 15/1000000) = $0.15 + $0.15 = $0.30
- 会话小时成本: 2 * $0.08 = $0.16
- 总成本: $0.46
```

## 风险与局限

### 已知局限

1. **供应商锁定**: 深度集成 Claude Platform，迁移成本高
2. **成本不可预测**: 长周期任务的会话小时成本可能超出预期
3. **功能可用性**: 多 Agent 协作等功能仍处于研究预览，需申请访问
4. **自定义受限**: 编排逻辑由 Anthropic 控制，无法完全定制
5. **地域限制**: 目前仅限部分区域可用（需确认具体支持区域）

### 待验证问题

- **SLA 承诺**: 生产环境的可用性保证是多少？
- **数据驻留**: 会话数据存储在哪些区域？是否符合 GDPR 等合规要求？
- **并发限制**: 单账户可同时运行多少会话？
- **冷启动延迟**: 新会话启动需要多长时间？
