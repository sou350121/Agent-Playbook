## 是什么 / 解决什么问题

2026 年 3 月 10 日，NVIDIA CEO 黄仁勋发表自 2016 年以来的第七篇公开长文《AI Is a 5-Layer Cake》，系统阐释了 AI 产业的底层逻辑。这篇文章的核心贡献不是技术细节，而是一个**第一性原理框架**：为什么 AI 不是"一个聪明的应用"或"单个模型"，而是像电力和互联网一样的基础设施。

黄仁勋指出，计算范式发生了根本性转变：

**传统计算（Pre-recorded Software）**：
- 人类描述算法 → 计算机执行
- 数据必须结构化存储
- 通过精确查询检索（SQL 是这一范式的巅峰）
- 软件是"预录制"的，执行时只是回放

**AI 计算（Real-Time Intelligence）**：
- 计算机理解非结构化信息（图像、文本、声音）
- 理解上下文和意图
- **每次响应都是新生成的**，依赖提供的上下文
- 软件在推理，按需生成智能

这个转变意味着整个计算栈必须重新发明。五层架构就是对这个新栈的解构。

## 实用评估

### 什么场景值得用

1. **AI 基础设施投资决策**：五层架构提供了判断投资优先级的框架。例如，如果应用层需求爆发，应该向下追踪哪一层是瓶颈（当前通常是能源和芯片产能）。

2. **Agent 应用开发方向判断**：黄仁勋明确指出"未来几年传统软件和 App 形态或将消失，AI Agent 可能成主流"。这意味着：
   - 传统 CRUD 应用将被 Agent 取代
   - 成功 Agent 应用会拉动下方所有层（模型推理需求→基础设施→芯片→能源）
   - 开发 Agent 时应考虑对下层的拉动效应（如推理成本、延迟约束）

3. **技术栈设计**：理解五层依赖关系有助于避免架构误判。例如：
   - 不要假设模型层可以独立优化（受基础设施约束）
   - 不要忽略能源成本（token 生成的物理成本）

4. **产业趋势分析**：框架解释了为什么 AI 工厂建设规模空前（"数千亿美元投入，数万亿美元仍需建设"），以及为什么劳动力需求从纯软件工程师扩展到技工（电工、管道工、网络技师）。

黄仁勋的框架对具身智能（VLA）研究有直接启示：

   - 边缘推理的能源约束（Jetson 等平台）
   - 实时性要求对芯片层的压力
   - 物理世界交互对模型训练数据的需求

2. **开源模型的拉动效应**：DeepSeek-R1 案例表明，开源推理模型可以激活全栈需求。对 VLA 研究而言，开源 VLA 模型（如 OpenVLA）可能产生类似效应。

3. **基础设施瓶颈**：VLA 训练需要大规模基础设施，框架提醒我们关注能源和芯片产能约束。

### 对 AI 应用开发的影响

1. **Agent 优先策略**：黄仁勋明确预测 Agent 将成为主流应用形态。这意味着：
   - 新应用应优先考虑 Agent 架构而非传统 UI
   - 工作流自动化（AI Workflow）是最快增长场景之一
   - 传统 SaaS 应用需规划 Agent 化路径

2. **成本结构变化**：应用层开发者需理解 token 生成的物理成本（能源→芯片→基础设施），这会影响定价策略和架构选择。

3. **开源模型红利**：利用开源模型（如 DeepSeek-R1、Llama 系列）可以降低模型层成本，但需评估对下层基础设施的需求。
