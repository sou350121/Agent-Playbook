## 是什么 / 解决什么问题

2026 年 3 月，OpenAI 正式推出 **Safety Bug Bounty** 计划，这是首个由前沿 AI 实验室发起的、专门针对 AI 滥用和安全风险的公开漏洞赏金项目。该计划与现有的 Security Bug Bounty 并行运行，但覆盖范围有本质区别：

**传统安全漏洞**（Security Bug Bounty 覆盖）：
- API 认证绕过
- 服务器端代码执行
- 数据库注入
- 基础设施层攻击

**AI 特有风险**（Safety Bug Bounty 新增覆盖）：
- Agent 劫持（提示词注入导致执行有害操作）
- 敏感信息外泄（Agent 被诱导泄露用户数据）
- MCP（Model Context Protocol）第三方风险
- 模型推理信息泄露
- 账户/平台完整性信号绕过

这一划分的核心意义在于：**承认 AI 系统的安全边界已超越传统代码层，延伸到语义交互层**。一个完全符合传统安全标准的 Agent 系统，仍可能因提示词注入而被劫持执行有害操作——这类风险此前处于灰色地带，现在被正式纳入漏洞定义。

## 技术架构拆解

### 核心设计决策

**1. 风险分层：Agentic Risks 作为独立类别**

OpenAI 将 "Agentic Risks including MCP" 列为首要类别，明确涵盖：
- **第三方提示词注入与数据外泄**：攻击者文本能够以 ≥50% 复现率劫持受害者 Agent（包括 Browser、ChatGPT Agent 及类似产品），诱导其执行有害操作或泄露敏感信息
- **大规模未授权操作**：Agent 产品在 OpenAI 网站上大规模执行禁止操作
- **MCP 合规要求**：任何 MCP 风险测试必须遵守第三方服务条款

这一设计决策反映了 OpenAI 对 Agent 生态风险演进的判断：**提示词注入已从"越狱"演变为"工具劫持"**，攻击目标从获取受限内容转向执行实际有害操作（如转账、数据窃取、权限提升）。

**2. 专有信息保护：推理过程纳入防御范围**

计划明确将 "Model generations that return proprietary information related to reasoning" 列为漏洞。这意味着：
- 诱导模型暴露其推理链（chain-of-thought）属于可报告漏洞
- 通过特殊提示词获取模型内部决策逻辑可能被认定为安全事件
- 这一保护范围超越传统商业机密，延伸至 AI 系统的认知过程

**3. 漏洞与内容策略的边界划分**

计划明确区分：
- **In Scope**：导致可证明安全或滥用影响、具有明确修复路径的缺陷
- **Out of Scope**：无实际安全影响的内容策略绕过（如让模型说粗话、返回搜索引擎可查信息）

这一划分解决了长期存在的模糊地带：**并非所有"越狱"都是安全漏洞**，只有那些导致实质性伤害的才纳入赏金范围。

## 实用评估

### 什么场景值得用

**1. Agent 框架开发者**
- 如果你正在构建基于 OpenAI API 的 Agent 系统（如 AutoGen、LangChain 应用），必须了解此计划定义的 risk pattern
- 建议对照计划中的 Agentic Risks 类别进行自查，确保系统不会因提示词注入而执行未授权操作
- 特别关注 MCP 集成场景——计划明确要求"必须遵守第三方服务条款"

**2. AI 安全研究员**
- 这是首个由前沿实验室公开接受的 AI 安全漏洞提交渠道
- 研究方向可聚焦：跨 Agent 提示词注入、MCP 链式攻击、推理信息提取技术
- 赏金机制为 AI 安全研究提供商业化路径

**3. 企业 AI 部署合规审查**
- 计划定义了"可接受 AI 风险"的官方边界
- 企业可参照此标准评估内部 AI 系统的安全性
- 特别是"50% 复现率"门槛——低于此阈值的攻击可能不被认定为漏洞

### 什么场景不值得用

**1. 纯内容生成应用**
- 如果你的应用只调用 Chat Completions API 生成文本，无工具调用、无外部集成
- 此类应用的风险主要是内容策略绕过（明确 out of scope）
- 无需为此计划调整架构

**2. 封闭环境实验**
- 计划要求漏洞必须造成"plausible and material harm"
- 纯理论攻击、无实际伤害路径的研究不符合提交条件
- 建议先评估伤害链完整性再投入研究时间

**3. Jailbreak 研究者**
- 计划明确：jailbreaks out of scope（除非是官方私测活动如 Biorisk）
- 让模型说粗话、返回公开可查信息不属于漏洞
- 此类研究应转向官方私测活动（如 bio-bug-bounty 系列）
