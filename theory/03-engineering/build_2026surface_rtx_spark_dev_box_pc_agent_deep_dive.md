## 实用评估

### 什么场景值得用

- **本地模型调试**: 需要反复加载/修改模型参数的场景。128GB 统一内存 + 1 PFlops 算力足以跑中等规模模型（如 MAI Thinking 1 的 35B active 参数）进行推理和轻量微调。
- **多 Agent 并行开发**: GitHub Copilot app 支持多 issue 会话 + Git worktree 隔离。Dev Box 的 20 核 + 128GB 内存可同时跑多个 Agent 会话而不卡顿。
- **企业内网隔离开发**: 对数据出境有严格要求的场景（金融、医疗、政府），本地算力意味着数据不出域。
- **低延迟编码体验**: 本地运行 MAI Code 1 Flash 等模型，代码补全和 Agent 建议的延迟远低于云端方案。

### 什么场景不值得用

- **大规模模型训练**: 128GB 内存和 1 PFlops 算力对于全量微调大模型（如 1T 参数的 MAI Thinking 1）远远不够，仍需云端 GPU 集群。
- **移动办公**: 桌面形态，100W 功耗，需要持续供电——不是笔记本替代品。

### 迁移成本

从传统开发笔记本迁移到 Dev Box：
- **硬件**: 即插即用（USB-C、USB-A、HDMI、以太网），无需额外配置
