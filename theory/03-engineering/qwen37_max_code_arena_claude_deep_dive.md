### 核心设计决策

Qwen3.7-Max 的编程能力跃升，核心来自两个训练方法的升级：

**1. 环境扩展（Environment Expansion）**

编程训练时，每个任务被拆成三个独立维度：任务本身、执行框架、验证方式，三者自由组合。同一道题，有时在 Claude Code 框架里做，有时在 OpenClaw 里做，有时换一种验证方式。

效果是模型被迫学会解决问题的通用策略，而非「在某个特定框架里取巧」。这解释了为什么 Qwen3.7-Max 在 Claude Code、OpenClaw、Qwen Code 等多个框架里表现都很稳定，没有出现「在自家框架里很强、换一个就拉胯」的偏科现象。

训练中引入「动态累积生存博弈」框架：让模型在持续变化的模拟环境中做超过一千步的连续决策，自己建立假设、根据反馈调整策略，且不能因为跑太久就上下文腐化。
