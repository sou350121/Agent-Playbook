## 是什么 / 解决什么问题

Project Glasswing 是 Anthropic 在 2026 年 4 月发起的一项行业联合防御计划，核心动因是一个令人不安的发现：他们训练的新 frontier 模型 **Claude Mythos Preview** 在网络安全任务上的能力已经达到了一个临界点——它可以自主发现并利用软件漏洞，能力超越绝大多数人类安全专家。

这个发现带来一个紧迫问题：如果这样的模型能力扩散到恶意行为者手中，全球关键软件基础设施可能面临灾难性风险。Project Glasswing 的应对策略是**在攻击者之前武装防御者**：

- **受限访问**：Mythos Preview 不公开发布，仅向经过筛选的防御性合作伙伴开放
- **行业协作**：11 家创始合作伙伴（AWS、Apple、Broadcom、Cisco、CrowdStrike、Google、JPMorganChase、Linux Foundation、Microsoft、NVIDIA、Palo Alto Networks）共同使用模型加固各自系统
- **开源支持**：额外向 40+ 关键开源项目维护者提供访问权限
- **资金投入**：Anthropic 承诺提供高达 $1 亿美元的模型使用积分 + $400 万直接捐赠给开源安全组织

这标志着 AI 安全策略的一个转折点：从「防止模型被滥用」转向「在模型能力普及前建立防御优势」。

### 核心设计决策

## 实用评估

### 什么场景值得用

- **关键基础设施运营方**：电力、金融、医疗、交通等系统的软件维护团队 — Mythos Preview 已证明可发现存活数十年的高危漏洞
- **开源安全维护者**：Linux kernel、OpenBSD、FFmpeg 等基础库的维护者 — 可获得 Anthropic 提供的免费扫描支持
- **企业安全运营中心**：拥有大型代码库的企业（如合作伙伴列表中的科技公司）— 可集成到现有安全流程中
- **安全研究团队**：专注于漏洞挖掘的学术/工业实验室 — 可申请受限访问进行研究

### 什么场景不值得用

- **一般应用开发者**：非关键业务应用、内部工具 — 获取访问权限的成本高于收益
- **预算有限的小团队**：即使未来开放商业访问，预计成本会很高（Anthropic 已投入 $1 亿积分）
- **合规驱动而非安全驱动的团队**：如果只是为了满足审计要求，现有 SAST/DAST 工具更经济
- **等待公开披露的团队**：Mythos Preview 发现的漏洞会先私下披露，公开信息有 3-4 个月延迟

### 迁移成本

**当前无法「迁移」** — Mythos Preview 不是可购买的产品，而是受限的研究/合作伙伴计划。

对于希望提升自身安全能力的团队，建议采取以下**替代方案**：

1. **采用类似工作流**：使用现有 AI 编码助手（如 Claude Code + Opus 4.6）搭建内部漏洞扫描流程
2. **加强模糊测试**：集成 AFL、libFuzzer 等工具到 CI/CD
3. **参与开源安全生态**：支持 OSS-Fuzz、OpenSSF 等组织
4. **关注披露信息**：跟踪 Anthropic Red Team 博客的后续披露（承诺在修复后公开细节）
