## 是什么 / 解决什么问题

AI 推理市场正经历爆发式增长。GPT-4o、Claude、Gemini 等大模型的广泛应用，使得推理算力需求远超训练需求。然而，当前 AI 算力市场被英伟达垄断（约 80% 市场份额），GPU 架构在多卡互联时面临带宽瓶颈、功耗过高、部署复杂等问题。

Cerebras 的解决方案从根本上不同于英伟达：不是制造更好的 GPU，而是重新定义芯片的边界。其 Wafer-Scale Engine (WSE) 将整个硅晶圆（而非切割后的小芯片）做成一颗巨型芯片，单芯片集成数万核心、数十 GB 片上内存，彻底消除多卡互联需求。

## 实用评估

### 什么场景值得用

- **大规模推理部署（千卡级以上）**：WSE 的单芯片架构在大规模推理时，可显著降低多卡互联带来的延迟和功耗。对于日处理数亿 token 的服务商，推理成本可能降低 5-10x（据 Cerebras 官方数据，待第三方验证）。
- **云服务商自建算力**：与 OpenAI 签 200 亿美元合作协议表明，超大规模买家认可其价值主张。其他云服务商（AWS/GCP/Azure）若希望降低对英伟达的依赖，Cerebras 是少数可选方案之一。
- **对推理成本极度敏感的场景**：整片晶圆架构的理论推理成本低于 GPU 集群，特别适合 LLM API 提供商、搜索引擎推理后端等。

### 什么场景不值得用

- **模型训练**：Cerebras 目前主要聚焦推理场景，训练生态（框架支持、分布式训练工具链）远不如 CUDA 成熟。
- **中小规模部署**：迁移到 Cerebras 需要重写推理代码（从 CUDA 迁移到 Cerebras 自有框架），中小团队ROI 不划算。
- **依赖 CUDA 生态的项目**：PyTorch/TensorFlow 的 CUDA 后端、大量开源模型的 GPU 优化，迁移成本极高。
- **需要多模态/特殊算子支持**：CUDA 生态的算子库（cuDNN、TensorRT 等）覆盖广泛，Cerebras 的算子支持仍在完善中。
