## 敘事斷裂偵測

本週最刺耳的斷裂，打在「Agent 需要更大更強模型」這條主流假設上。

反例三連：uncut——7 MB 單二進制 Go coding-agent harness，拒絕任何靜默上下文截斷（11-06）；vercel-labs/agent-desktop——用操作系統無障礙樹替代截圖來點界面（11-07）；Orkas——把已裝的 Claude Code / Codex / OpenCode 收編成一支本地 AI 團隊（11-07）。三條做的是同一件事：**不換模型，只換外殼與感知通道**。同期 DeepSeek V4.1 Flash 以 >1000 tok/s、1M 上下文接入 Gateway（11-08），Mistral 放出 1T 參數的 Le Chonk（11-08）——能力仍在狂飆，但讓人動手的是那些 7 MB 的東西。Software 3.0 的「模型即產品」假設正在被侵蝕：產品的位置移到 harness 與感知層。

第二處斷裂針對 MCP 假設。AWS 在 11-07 出 Part 2：Okta Cross App Access 加 AgentCore Gateway 管住 agent 的憑證路徑。前幾輪我們說「協議管能連什麼、IAM 管允許做什麼」；這週企業側給出更明確的答案——**憑證路徑**才是控制點。MCP 仍在，但已退化成連接埠，權力落在 Okta 這類身份層。工具+新發布 66.2% 恰好證明：生態在堆接入件與外殼，沒人在爭協議。

第三處是方法論。OpenAI LifeVal 用 3,995 人調查構建日常任務 agent 評測（11-07）——本週唯一一條真正的評測信號。agent 從 demo 走向日常之後，「能不能跑」不再是問題，「跑得像不像人想要的」才是。而我們自己：Active Assumptions 連續為空、upstream 1406 條 100% unknown（第五週），仍在記錄，不在假設。

## 領域方向感知

重心正從「模型能力」移向「外殼、感知與身份」。23 篇 deep dives 裡，harness/外殼類至少 4 條（MiniMax mcode-stack、uncut、Orkas、agent-desktop），身份與憑證 1 條（AWS + Okta），評測 1 條（LifeVal），模型發布僅 2 條（Muse Glimmer、Le Chonk）。比例接近 6:2——外殼壓過模型。

結構是「碎片化的外殼 + 收斂的接入」。碎片化在個人側：HackerTube 移植潮（11-06）、Orkas 收編多家 CLI、uncut 自造 harness，人人都在造自己的殼；收斂在企業側：Gateway 接模型、Okta 管憑證、AgentCore 管工具，三件套成形。比上一輪「模型層聚合、執行層分散」多了一層——身份。

MiniMax 開源 mcode-stack（自家團隊每天在用的 skills 與工作流）值得單列：把內部實戰配置公開，等於把「怎麼用」變成公共品，這比開源模型更難複製。

可證偽命題一：若下一週期出現跨廠商 agent 憑證/身份標準，則平台化在身份層勝出；若各家仍各自接 Okta 或自建，身份碎片化將成為落地首要摩擦。

可證偽命題二：若「7 MB 級 harness」與「無障礙樹取代截圖」在兩週內出現第二、第三個實現，則競爭焦點已從模型能力轉向感知通道與上下文保真度。

可證偽命題三：若 LifeVal 這類以人類調查為基準的日常任務評測在一個月內被其他機構採用，則 agent 評測從刷分轉向需求對齊；若無人跟進，則只是單點嘗試。

## 最值得讀 / 最值得疑

**最值得讀：uncut——7 MB 的 harness（11-06）。** 它做的事只有一件：拒絕靜默上下文截斷。但這件事正是所有 agent 系統最隱蔽的失效來源——你以為模型在推理，其實它沒看到那段上下文。配合 agent-desktop 用無障礙樹取代截圖（11-07），可以看出本週真正的技術路線不是「更大的模型」，而是「更誠實的上下文」。對 CTO 的含義：agent 的可觀測性比模型選型更值得投資。

**最值得疑：「能力側狂飆代表產品進步」。** DeepSeek V4.1 Flash 的 >1000 tok/s、1M 上下文與 Le Chonk 的 1T 參數確實亮眼，但同期最讓人動手的是 7 MB 的 Go 二進制。把模型指標當產品進步，會讓你錯過這一輪真正的競爭維度——上下文保真度與感知通道。
