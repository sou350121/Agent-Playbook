## 敘事斷裂偵測

本週最響的一聲斷裂，來自微軟：「vibe coding 暫停鍵——燒 token 已經比員工貴了」。這不是產品新聞，而是對過去一年最流行假設的正面否證：自然語言即編程，成本會持續下降。

同向證據有三條。Vercel AI Gateway 新增 session affinity 視圖，按 coding agent 歸併會話、計算緩存命中率——同一功能分兩次出現（10-18、10-19），說明這是被反覆強調的重點而非附帶功能；stablyai/orca 直接主打「用自己的訂閱跑一隊 coding agent」。三條合起來指向同一件事：agent 的評估軸已經從「能不能做」換成「一隊 agent 扛不扛得住成本」，質量指標變成了緩存命中率與訂閱額度。Software 3.0 的樂觀假設，正在被會計部門侵蝕。

第二處斷裂針對平台化假設。Vercel AI Gateway 兩天內接入兩家不同廠商的模型：Liquid AI d1-ultra（輸出結構化概率的決策模型，10-16）與 GPT-6.1 Sol（10-18）；Perplexity 則開源了可自託管的 Firecracker agent 沙箱（10-18）。一邊是 gateway 把模型變成可替換件，一邊是沙箱把執行層去中心化——「模型層會平台化並鎖住用戶」這條假設被兩面夾擊：鎖點正在從模型移向 gateway 與沙箱這類基礎設施。

第三處是我們自己的鏡子。Active Assumptions 連續為空，upstream 2756 條信號 100% 落在 unknown（上週 1903 條同樣如此）；而 deep dives 側卻是 REWIND（不確定性引導軌跡修復）、INTACT（凍結骨干上誘導潛在推理）、Are We Really Measuring Forgetting（多模態 LLM 遺忘評測的陷阱）這類極細的工程問題。上游海量未歸類、下游窄而深——「人人用 agent 寫軟件」的宏大敘事，正被「怎麼測遺忘、怎麼在凍結模型上做推理」拉回地面。

## 領域方向感知

重心正從「模型能力」移向「agent 的運行成本與可審計性」。16 篇 deep dives 中，與 gateway、沙箱、會話緩存、訂閱額度直接相關的至少 5 條（AI Gateway 兩次 session affinity、d1-ultra 與 GPT-6.1 Sol 接入、Perplexity SPACE、orca），加上微軟的 token 成本暫停，接近四成。價值捕獲點從「模型多強」轉向「誰能讓一隊 agent 跑得便宜且可審計」——session affinity 與緩存命中率就是新 KPI。

工具層呈現「聚合 + 去中心化」的雙向拉扯，但這不是矛盾而是分工：模型層聚合（gateway 把多廠商模型變成可替換件），執行層分散（開源沙箱、自帶訂閱跑 agent）。

可證偽命題一：若下一週期出現跨平台的 agent 成本/沙箱標準——統一的會話歸併與計費口徑被多平台採納——則聚合勝出，走向受控平台化；若各家繼續各造 gateway 與沙箱而無共同口徑，則去中心化的執行層混戰持續，平台化在模型層落空、在 gateway 層重演。

可證偽命題二：upstream 2756 條全 unknown 若再持續一週，則「上游與 AI App 敘事無映射」應判定為結構性缺陷，而非偶發。

## 最值得讀 / 最值得疑

**最值得讀：agent 成本已成為一級工程問題。** 微軟喊停 vibe coding（10-19）、Vercel AI Gateway 兩次推送 session affinity、orca 主打自帶訂閱跑 agent——三個獨立來源在三天內指向同一件事。這不是巧合，是市場在重新定價。如果你的 agent 平台還沒有會話級的成本歸因能力，你現在缺的是儀表盤，不是模型。

**最值得疑：「實驗」類 5 條代表生態回暖。** 7.7% 的新類別很容易被讀成多樣性提升，但同週趨勢類掉到 1.5%、strategic_highlights 連兩週為空。更合理的解釋是分類漂移：原本該歸入觀點或趨勢的內容，被吸進了「實驗」。在趨勢類恢復之前，不宜把新類別的出現當成生態活力的證據。
