# AI 应用双周深度推理 | 2026-11-12 – 2026-11-25

> 基于 Agent-Playbook 过去 14 天的系统数据 + 全域分析上下文 | 2026-11-25

## 本期核心信号

**一、MCP 赢了协议战，然后变得不值钱。** Kimi Hosted Agents 把 harness 做成云托管（11-11）、Claude Code 2.1.319 把 MCP 任务后台化并加入 denyInsteadOfPrompting（11-13）、DeepSeek Harness 日活 154 万、日耗 92 万亿 token 后官宣插件市场（11-13）。三家都在做同一件事：harness 是产品，MCP 只是接头。接入层彻底商品化，差异化全部转移到调度与策略。

**二、加速的来源变了。** METR 对 Anthropic 的独立评估给出约 2 倍的能力提升速度，且多数加速来自 AI 自身参与研发（11-12）。这不是又一条"模型变强了"的新闻——它意味着研发闭环本身成了竞争资产，而 harness 正是这个闭环的载体。

**三、系统仍在记账，不在判断。** 118 条 picks、38 篇 deep dives，strategic_highlights 与 Active Assumptions 双双为空。工具 43（36.4%）加新发布 31（26.3%）吃掉 62.7%，趋势仅 7（5.9%）、实验 4（3.4%）。素材足够写十组命题，系统一条没提。

## 工具与平台收敛

胜负已分，但赢的方式很讽刺：**MCP 统一了接入，因此失去了定价权。**

AWS 让服务端 MCP server 直读企业数据湖（11-12）、Pinky 用 MCP 让任意 agent 操作真机 iPhone/Android（11-12）——接入门槛降到接近零。当任何人都能接、任何 agent 都能用，协议本身就不再是护城河。

碎片化发生在 harness 侧：Kimi 做托管、Claude Code 改调度、DeepSeek 建插件市场，每家都在自建执行层。收敛发生在接入侧，分散发生在调度侧——这是本期最不该被忽略的结构。

真正的赢家不是模型厂，是**掌握调度与策略的那一层**。denyInsteadOfPrompting 这个默认值的改动就是证据：权限决策从"人来点确认"变成"策略预先裁定"，权力从界面移到策略引擎。

## 工程范式变迁

从概念变标准的有两样。

**异步执行。** Claude Code 后台化、Kimi 托管 harness、DeepSeek 92 万亿 token 日耗——父会话不阻塞不是优化项，是长时 agent 的运行前提。同步架构在这一量级上已经不成立。

**推理成本工程。** Together AI 的 Polymorphic Inference 做开源模型自我调优（11-13）、Gemini Omni 1.2 Flash 原生视频生成 GA 同时降价 30%（11-12）。降价已成常态手段，不是事件；能吃到结构性收益的只有自建推理调优的人。

退潮的是"更大模型等于更强产品"。同期模型侧仍有腾讯 Hy4 770B/49B 激活并首次支持 Computer Use（11-11）、Claude Fable 5.2 / Mythos 5.2 同底模双 SKU、$8/$40 且输出快 30%（11-14）——规格依旧亮眼，但讨论热度已经让位给 harness 与调度。

## 战略级事件聚焦

**METR 的 2 倍加速评估（11-12）。** 这是本期唯一触及"系统自我改进"的证据。它的含义不是模型更强，而是**加速的因果链变了**：过去是人堆算力，现在是 AI 参与自己的迭代。若这条成立，那么所有以"人类研发速度"为隐含假设的路线图都要重估。值得注意的是，38 篇 deep dives 里它是最重的一条，却没有被转成任何可证伪命题。

**DeepSeek Harness 的插件市场（11-13）。** 154 万日活、92 万亿 token 日耗之后再开市场，路径清晰：先做规模，再做分发。但同期没有任何信号谈插件的版本、审核与回滚。开市场容易，管分发难——这是一个已经被写进脚本、却没人验收的风险。

**Pinky 用 MCP 操作真机（11-12）。** 一句话概括：MCP 从读数据走到点手机屏幕。这让"agent 能操作真实设备"从 demo 变成可复用的接入件，也让权限边界的讨论从理论变成必须。

## 跨信号关联

**关联一：METR 测量结果，harness 提供手段。** METR 说加速来自 AI 参与研发（11-12），Kimi 把 harness 做成托管服务（11-11），DeepSeek 用它跑出 92 万亿 token 日耗（11-13）。三者合起来看：自我改进不是抽象能力，而是"调度 + 上下文 + 工具"的工程闭环。谁掌握 harness，谁就掌握加速的开关。

**关联二：能力侧往前冲，评测侧在拆台。** 腾讯 Hy4 首次支持 Computer Use、权重近期开源（11-11），Pinky 能让 agent 操作真机（11-12）——能力快速收敛到"能操作真实设备"。而 VLA 侧同期出现 Is Your Robot's Memory Just a Clock?（11-11），指出记忆增强策略可能只是在学时间相关性。这个温差是本期最有价值的信号：真正的瓶颈不是能不能操作，而是操作里有多少是真理解。

**关联三：开源压底，托管收顶，商业化从卖权重转向卖运行环境。** Kimi Hosted Agents（11-11）、Hy4 权重近期开源（11-11）、Omni Flash GA 降价 30%（11-12）三件事拼在一起，是清晰的分工重排：开源压低模型底价，托管承接运维复杂度。商业价值从"模型"迁移到"运行环境"。

**关联四：VLA→AI App 十连发，主题是可证伪性。** 10 条跨域信号全部 R001，关键词 prediction（4）、vision-language（4）、world model（1）。最重的两条是 How Much of Your VLA Is kNN（溯源性质疑）与 RoboACE 对抗式协同进化（自我改进路径）——一个拆台，一个搭台，与 AI App 侧的 AgentRun、METR 形成跨域镜像。

## 非显而易见的洞见

**一、所有人盯 Computer Use，没人盯"记忆是不是真的"。** Is Your Robot's Memory Just a Clock?（11-11）指出记忆增强 VLA 可能只是在学时间相关性。这个怀疑应当原样套到所有 agent 的长期记忆上：你的记忆模块，可能只是一个按时间排序的检索器，而你会把它误读为推理能力。

**二、所有人盯 harness 性能，没人盯 harness 的所有权。** Kimi 托管、DeepSeek 插件市场都在把 harness 变成平台资产。当调度、日志、上下文与策略都在别人手里，锁定不是通过合同发生的，是通过架构发生的——而且通常要 3-6 个月后才会痛。

## 范式转换观察

Software 3.0 的重心已经从"模型即产品"移到"执行即产品"。denyInsteadOfPrompting 这类默认值改动，比任何模型发布都更能决定 agent 能否进生产——因为它假设了在规模化系统里，人不该是权限决策链的一环。

Vibe Coding 层面，本期出现的是"托管化"而非"更聪明"：Kimi 把编码 agent 变成云服务，Claude Code 把任务搬到后台。Agent Native 的进展体现在协议下沉、策略上浮——MCP 通吃接入，策略引擎接管决策。

## 如果你是 AI 工程负责人

**一、把 harness 当架构核心，而不是周边工具。** 因为 Kimi、Claude Code、DeepSeek 都在把调度做成产品（11-11 至 11-13），否则你以模型选型为中心的架构，会在一次平台定价调整后整套推倒。

**二、把成本优化当推理工程，而不是采购谈判。** 因为 Polymorphic Inference 自我调优（11-13）与 Omni Flash 降价 30%（11-12）改的是账单结构，否则你永远只能拿到谈判价，拿不到结构性收益。

**三、把"记忆是否只是时钟"列为验收项。** 因为在你的记忆模块上做一次时间打乱测试，只需几天，否则你会把检索延迟长期误判为推理能力，并据此做错误的架构投资。

## 知识缺口

三个问题本期无解：**第一，** METR 的 2 倍加速只给了结果，没给可复现的方法——无法判断它是普遍规律还是单一实验室现象。**第二，** 插件市场与 harness 托管都没有版本、审核、回滚的任何数据，"分发层风险"目前仍是推断而非事实。**第三，** 社交信号连续 15 天为 0，我们对"社群怎么想"的判断完全没有输入，这会让所有产业结论系统性偏向厂商叙事。
